**Foundational sources — completed set + trackable.** Was 2 providers (LexisNexis, TransUnion), fire-and-forget links. Now 6: all THREE credit bureaus (TransUnion/Equifax/Experian — a freeze only works at all three, so a partial set was an honesty/correctness bug), LexisNexis, The Work Number (employment/income freeze), ChexSystems (banking).   - GOTCHA fixed: `summarizeNodes` (seo/lib/exposure-graph-db.mjs) now `continue`s on surface_type='foundational' so these self-report nodes don't inflate the Exposed/found counts. **Identity Protection Score (2026-08-09).** One honest headline in DigitalFootprint: `protection.score` = share of RECOMMENDED protections in place = weighted completion `(2*foundationalDone + 1*brokersControlled) / (2*FOUNDATIONAL_ACTION_COUNT + 1*(controlled+exposed))`. Foundational weighted 2x (higher-leverage). Labeled "actions taken, not a guarantee of safety" (honest — not a safety score). Plus `protection.next` = single highest-impact next step, priority: the 3 credit freezes → Work Number/ChexSystems/LexisNexis freezes → worst exposed broker (by severity) → any remaining foundational lever. Rendered as a hero at top of the full footprint view (score % + bar + "Next best step" + Do-this button: foundational opens provider URL, broker opens OptOutGuide) AND on the dashboard compact card (score + Next + Manage). scoreTone: ≥70 green, ≥35 amber, else red.

**Protection-score history + trend.** `/api/protection-history` + `protection_snapshot` table (user_id, day, score; one row/day, latest wins). DF records today's snapshot once the graph loads (snapRecorded ref guards) and fetches the series; renders a small SVG `Sparkline` + "▲ +N since you started" delta in the score hero. Client `recordProtectionSnapshot`/`fetchProtectionHistory` in memberEnrichment. Commit 353025b.

**First-run protection plan (guided onboarding).** Top-of-footprint checklist card, 5 steps auto-derived from real state (no separate wizard): 1) claim identity (`mapped`) 2) freeze credit at all 3 bureaus 3) remove from brokers (`progress.total>0 || controlled>0`) 4) lock income/banking/risk files (Work Number/ChexSystems/LexisNexis freezes) 5) add the extension (`hasExtension`). Each row shows a CTA (claim/scroll-to-foundational/Remove-me/get-extension); auto-HIDES once all 5 done so it never nags. Freeze CTAs scroll to `foundationalRef`.
