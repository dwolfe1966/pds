# HomeFacts — open-web data appendix

_Compiled 2026-08-22 from public third-party sources (SimilarWeb, HypeStat, SEMrush-derived, registry stats)
via web research. All figures are **directional third-party estimates** unless marked first-party. This is the
evidence base under both one-pagers; the paid-tool pulls (see `sources/`) will firm the ranges into hard numbers._

## 1. Authority & backlinks
- **Moz Domain Authority 47** · Page Authority 51 (Moz / HypeStat)
- **54,188 backlinks** from **2,106 referring domains** (31,632 follow) (HypeStat)
- Domain registered **1996 (~30 years)** (WHOIS)

## 2. Traffic volume & trend — _estimators disagree; this is the soft spot_
- **SimilarWeb:** ~**157K visits/mo** (3-mo avg), **+15.84% MoM (growing)** — global rank #237,802, US rank #48,626
- **HypeStat:** ~**792K visits/mo** (~26.1K/day) — a higher-model estimate
- **SEMrush-derived:** ~**47K organic visitors/mo**; SEMrush rank 33,092
- **Engagement (SimilarWeb):** bounce ~59%, **3.12 pages/visit**, **1:42 avg session** — an engaged site, not bounce-and-leave
- ⚠️ Estimators vary 5–15×. The audited figure is only available from homefacts.com's **Google Search Console** (post-deal).

## 3. Audience geography & sources
- **96.9% United States** · Canada 0.8% · Spain/Germany/India ~0.6% each (SimilarWeb)
- **Organic search 71.6%** (SimilarWeb) / **~87% search** (HypeStat); **paid 0%** — an SEO asset, not ad-bought
- _Implication:_ HomeFacts's real audience is domestic and organic — **distinct from the 97% Singapore bot traffic hitting our partner link** (first-party `web_events`).

## 4. Organic footprint & keywords
- **258,562 keywords ranking in Google's top 20** (SEMrush)
- **Organic cost-equivalent ~$26,322/mo** — what that organic traffic would cost as ads (SEMrush)
- **Top organic queries are person names:** "andrew james davis," "connor whitworth," "brian oneal bowling north carolina," plus address queries (SimilarWeb / HypeStat)
- Top-ranking page types are the **sex-offender registries** (`/offenders.html`, `/offenders/<State>.html`) (Google SERPs)
